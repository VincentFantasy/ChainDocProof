## 技术栈（与管理端一致）

- Vue 3.5（`<script setup>` 组合式 API）+ Vite 6 + JS（无 TS）
- Element Plus 2.9 全量引入 + @element-plus/icons-vue
- vue-router 4（hash 路由）+ vue-i18n 9（zh-CN / en-US，legacy: false，localStorage 持久化）
- axios：统一解包 `Result{code,message,data}`，`safeJsonParse` 防 BigInteger 精度丢失
- vitest：纯函数单测（边界值 + 异常输入）
- 不引入状态管理库（模块级 ref 共享登录态 / 次数）
- 不引入 ethers：钱包交互用原生 `window.ethereum`（EIP-1193）
- 开发端口 5174，Vite proxy `/api` → `http://127.0.0.1:8080`

## 关键设计

### 钱包交互（wallet.js + abi.js）
- 登录：`eth_requestAccounts` → `eth_chainId` 校验 11155111（不匹配则 `wallet_switchEthereumChain`，失败抛 WRONG_CHAIN）
  → `personal_sign(hex("ChainDocProof:" + address), address)` → POST `/api/user/auth/login`。
- 购买转账：`encodeTransfer(backendAddress, amountWei)` 拼 calldata → `eth_sendTransaction`（from/to/data）→
  轮询 `eth_getTransactionReceipt` 直到确认（10 分钟超时抛 TX_TIMEOUT；status 非 0x1 视为链上失败）→ 提交 `{quantity, txHash}`。
- 余额：`eth_call` DocToken 合约 `balanceOf(address)`，解码 32 字节 uint256。
- 金额运算：`amountWei = mulWei(quantity, unitPriceDocToken)`（BigInt，防 2^53 精度丢失与 2^256 溢出）。

### ETH 兑换 DocToken（2026-10-15 增补）
- 选择子（keccak256(函数签名) 前 4 字节；用 js-sha3 计算并以已知选择子 0xa9059cbb / 0x70a08231 验证过工具链）：
  `buyTokens(uint256)` = `0x3610724e`，`ethPerToken()` = `0xd22bc441`。
- 汇率读取：`eth_call` DocToken 合约 `ethPerToken()`（链上公开值，前端直读，不新增后端接口）。
- ETH 余额：`eth_getBalance`（返回 hex wei，BigInt 转十进制；非 ABI 编码，不走 decodeUint256）。
- 应付计算：`costWei = mulWei(tokensToWei(数量), ethPerToken)`，与合约 `tokenAmount * ethPerToken` 一致
  （DocToken 为 18 位小数，数量先 ×10^18 再乘汇率）；发送 `buyTokens(数量wei)`，`msg.value = weiToHex(costWei)`，
  合约多付自动找零。
- 复用：waitForTx（等链上确认）、receipt status 校验、mapWalletError（本地化错误）、BigInt 余额预检拦截。

### 错误处理
- HTTP 401（token 失效/后端重启）：清 token 跳登录页，重新签名即可。
- 上传 429：解析 message 中"N 秒"，上传按钮禁用 + 倒计时；上传成功后主动倒计时 60 秒。
- 钱包错误统一映射本地化文案：4001 用户拒绝 / NO_WALLET 未安装钱包 / WRONG_CHAIN 网络不符 / TX_TIMEOUT 超时。
- 购买 409：txHash 已用于购买（幂等提示）；余额不足（BigInt 比较）提前拦截。

### 页面与状态流转
- `useCredit` 模块级 ref：App 登录后刷新，存证/校验/购买成功后刷新；头部与页面共享。
- PENDING →「存证」（二次确认、扣 1 次、loading 约 1 分钟）→ STORED（显示 Etherscan 交易链接）。
- STORED →「校验」（隐藏 file input 重传原件 → 二次确认扣 1 次 → 结果弹窗）。
- 余额为 0：存证/校验按钮点击时提示"次数不足，请先购买"。
