## 二、后端新增接口与字段

现有 `GET /admin/**` 接口保持不动，仅新增两个只读接口。

### 1. `GET /admin/stats`（顶部统计概览）→ `Result<AdminStatVo>`

`AdminStatVo` 字段：

| 字段 | 类型 | 来源 |
|---|---|---|
| totalUsers | long | `UserDao.count()` |
| totalProofs | long | `ProofDao.countStats()` |
| storedProofs | long | `ProofDao.countStats()`（status='STORED'） |
| totalPurchasedCredits | long | `CreditLogDao.sumAllPurchase()` |
| totalMintCount | long | `MintDao.countAndSum()` |
| mintedTotalWei | BigInteger | `MintDao.countAndSum()`（SUM(amount)） |
| buyCount | BigInteger | `ChainGateway.getBuyCount()`（复用，读链上） |

### 2. `GET /admin/credit-logs?address=&type=`（次数流水）→ `Result<List<CreditLogVo>>`

- `address`、`type`（`PURCHASE`/`STORE`/`VERIFY`）均可省略，省略即不过滤。
- `t_credit_log` JOIN `t_user` 带出钱包地址，按 `id DESC`。

`CreditLogVo` 字段：`address`、`userId`、`type`、`amount`（int，正增负扣）、`proofId`（Long，可空）、`txHash`（可空）、`createdAt`。

### DAO 改动

- `UserDao`：加 `count()`
- `ProofDao`：加 `countStats()`（一条 SQL 返回 总数 + 已上链数）
- `MintDao`：加 `countAndSum()`（一条 SQL 返回 计数 + SUM(amount)）
- `CreditLogDao`：加 `sumAllPurchase()`、`listAll(String address, String type)`

### Service / Controller

- `AdminService`：加 `getStats()`、`listCreditLogs(String address, String type)`
- `AdminController`：加 `@GetMapping("/stats")`、`@GetMapping("/credit-logs")`

### 对接要点

- 鉴权：`Authorization: Bearer <token>`，7 天有效；**HTTP 401 或 body code=401 → 清 token 跳登录页**；服务重启全员掉线靠 401 兜底。
- 统一响应：以 body `code === 0` 判成败（业务错误 HTTP 仍是 200，错误码在 `code`）。
- 金额：`mints.amount` / `buyCount` / `mintedTotalWei` 均为 wei/BigInteger，`formatWei` 转 DocToken 展示；**mint 表单直接提交 DocToken 十进制字符串**（后端 `movePointRight(18)` 转 wei），前端不做 wei 换算。
- 分页：Element Plus 表格 + `el-pagination` 前端切片（测试网数据量级够用）。
