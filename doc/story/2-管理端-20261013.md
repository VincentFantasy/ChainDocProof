# 描述
实现管理端前端。后端 6 个核心管理端接口已在 v1.2 就绪（登录 / 用户 / 存证 / 发放 / 兑换），本次补齐前端界面，并按"完整增强"补充三项能力：顶部统计概览、各列表前端分页、次数流水查询（为此新增 2 个后端接口）。

# 技术选型
- 前端：Vue 3 + Vite + JavaScript（不引入 TypeScript）
- UI 组件库：Element Plus
- 状态：轻量 composable + localStorage 存 token，不引入 pinia（保持依赖精简）
- 路由：vue-router（hash 模式，免后端 URL 重写）

# 功能范围（完整增强）

核心 6 项：
- 账密登录（解析 429 限流"N 秒后再试"提示）
- 普通用户列表（余额 / 累计购买），可跳转该用户的存证
- 存证记录列表（可按用户地址筛选）
- DocToken 管理端发放（地址 + 数量，数量按 DocToken 十进制提交，后端转 wei），含发放历史
- DocToken 的 ETH 链上兑换次数（读合约 buyCount）

增强 3 项：
- 顶部统计概览（总用户 / 总存证 / 已上链 / 累计购买 / 发放次数与总量 / 链上兑换次数）
- 各列表前端分页
- 次数流水查询（可按地址 / 类型筛选：购买 / 存证消耗 / 校验消耗）

# 后端新增接口
- `GET /admin/stats`：统计概览（`AdminStatVo`）
- `GET /admin/credit-logs?address=&type=`：次数流水（`List<CreditLogVo>`，`t_credit_log` JOIN `t_user` 带出地址）

# 关键对接点
- 鉴权：`Authorization: Bearer <token>`，7 天有效；**HTTP 401 → 清 token 跳登录页**
- 统一响应以 body `code === 0` 判成败（业务错误 HTTP 仍是 200，仅 token 失效为 401）
- 金额：`mints.amount` / `buyCount` / `mintedTotalWei` 为 wei（BigInteger），前端 `formatWei` 转 DocToken 展示；mint 表单直接提交 DocToken 十进制字符串（后端 `movePointRight(18)` 转 wei），前端不做 wei 换算
- BigInteger 精度：Jackson 把大整数序列化成 JSON number，超过 2^53 前端会丢精度；响应体先正则把 16 位以上裸整数加引号再 `JSON.parse`（`safeJsonParse`）
