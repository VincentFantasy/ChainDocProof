# 描述
做一个链上资产存证服务的简单服务。
后端服务 + 简单 Solidity 存证合约。用户上传文件，后端计算文件 hash，把 hash 写到以太坊测试网合约；可以后续验证文件有没有被篡改。
另外做一个合约，生成一个叫DocToken的币。这个币可以使用ETH兑换，也可以在管理端生成到指定钱包。
存证合约时需要消耗指定DocToken币，消耗后销毁（打进0地址）

# 用户端
- 用户打开用户端后，需要连接钱包才能开始使用
- 用户在用户端需要支付DocToken，购买次数
- 用户在用户端选择文件，确认后可以点击上传。但需要限制用户60秒只能上传一个文件，这个60秒做成配置放在application.properties里
- 上传成功后，用户可以点击存证按钮，扣除次数，并且后端需要把文件上链
- 用户可以查询存证的文件列表
- 用户可以在存证文件列表处某条文件，点击校验，上传文件读取链上hash对比，并且扣除次数

# 后端
- 用户上传的文件计算文件的sha256 hash
- Web3j 调用合约，把 hash + 时间戳上链
- 用户文件上链后不要存放在服务器

# 管理端
- 用户登录依靠账户密码进行登录，但需要限制校验频率，输入错误全局限制60秒，这个60秒做成配置放在application.properties里
- 账户密码初始化使用sql脚本
- 可以查看普通用户的信息，购买次数
- 可以查看普通用户的存证记录，并且可以根据用户进行筛选
- 可以查看DocToken在管理端的发放次数
- 可以查看DocToken的兑换次数
